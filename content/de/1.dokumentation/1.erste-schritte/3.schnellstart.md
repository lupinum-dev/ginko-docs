Die Standard-Docs-Route lädt die aktive Seite aus der Docs-Collection und rendert das vollständige Dokument.

## Seitenabfrage

Nutze den aus `content.config.ts` exportierten Collection-Handle:

```vue
<script setup lang="ts">
import { docs } from "~/content.config";

const { page, previous, next } = await useContentPage(docs, {
  surround: { fields: ["description"] },
});
</script>

<template>
  <ContentRenderer v-if="page" :value="page" />
</template>
```

## Renderer-Regel

Übergib das vollständige Dokument an `<ContentRenderer>`. Übergib nicht `page.body`, weil der Renderer Dokumentmetadaten, Komponenten-Kontext und Inhaltsverzeichnisdaten benötigt.

## Links zur nächsten Seite

Vorherige und nächste Links stammen aus derselben Ginko-Content-Seitenabfrage. Dadurch bleiben Seitensteuerungen an der Collection-Reihenfolge ausgerichtet, ohne Tupel- oder Indexzugriffe im App-Code.
