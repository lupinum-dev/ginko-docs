Ginko Content is the content source for this starter. It reads Markdown and YAML from `content/`, validates documents through `content.config.ts`, and exposes typed query helpers to route components.

Writers can use app-level quick links without hard-coding localized paths: compare the [services]($main.services), review [references]($main.references), or send a [project brief]($main.projectBrief#contact).

## What this section covers

The getting started section keeps the first run tight:

- install dependencies,
- add the module,
- define collections,
- render the first docs page,
- confirm generated output.

## System shape

The docs route uses `useContentPage(docs)` for the current page. The sidebar uses `useContentTree(docs)` and normalizes the returned tree into the starter sidebar components.

## Done means generated

The migration is not complete at local dev render. It must also pass `nuxt generate`, sitemap checks, and in-app browser verification on generated routes.
