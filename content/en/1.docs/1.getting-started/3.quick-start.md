The default docs route loads the active page from the docs collection and renders the full document.

## Page query

Use the collection handle exported from `content.config.ts`:

```vue
<script setup lang="ts">
import { docs } from "~/content.config";

const { page, previous, next } = await useContentPage(docs, {
  surround: { fields: ["description"] },
});
</script>

<template>
  <ContentRenderer v-if="page" :value="page" />
</template>
```

## Renderer rule

Pass the full document to `<ContentRenderer>`. Do not pass `page.body`, because the renderer needs document metadata, component context, and table of contents data.

## Next page links

Previous and next links come from the same Ginko Content page query. That keeps page controls aligned with collection order without tuple/index access in app code.
