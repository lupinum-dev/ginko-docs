Choose a component, try the example, and copy its Markdown into your page. This reference covers all 34 built-in tags, including ordinary images. Replace the sample text, links, and image paths with your own content.

MDC means Markdown Components. It adds structured blocks to Markdown. A **property** (also called a **prop**) changes a component, such as its title. A **slot** is the content between its opening and closing lines.

## Start here

- Use capitalized component tags: `<Note title="Before you start">…</Note>`.
- Keep each opening tag on one line. Markdown between tags can span multiple lines. Nest components without changing their syntax.
- Quote text attributes. Use literal JSON for typed values: `:zoom="false"` or `:defaultValue='["first", "second"]'`. A bare boolean attribute such as `collapsible` means `true`.
- Use `<Figure src="/images/photo.webp" alt="Description" />` when a component has no body, and `<Kbd>Enter</Kbd>` inside a sentence.
- Write named slots as `<template #title>…</template>` inside their component.
- Properties are optional unless marked **required**. Property names and values stay in English in translated pages.
- Ginko Content parses these tags through Comark. Values must be static; JavaScript expressions, events, directives, and arbitrary styles are rejected.

Links beginning with `$docs/` refer to pages in the docs collection. Replace them with a matching page in your site; see [content links]($docs/authoring/links). Image examples use a file from this site's `public/images/` folder. Add your own image there before copying an image example.

Use the page contents to jump to a component. Paired tags, such as `tabs` and `tab`, share one section.

## Appearance

`appearance="quiet"` uses a restrained surface. `appearance="tint"` adds a colored surface. Each property table lists whether a component supports this setting. The default comes from the site's component-family setting, then its global setting; the built-in fallback is `quiet`. A card also inherits its surrounding `cards` appearance unless it has its own override.

Compare both styles in the [component showcase]($docs/components/component-showcase).

## accordion and accordion-item

Hide optional detail behind a question. Select the question to open or close it.

<Accordion type="single" collapsible defaultValue="preparation">

</AccordionItem>

</AccordionItem>
</Accordion>

**Copy into your Markdown file:**

```mdc [content/docs/component-example.md]
<Accordion type="single" collapsible defaultValue="preparation">
<AccordionItem value="preparation" title="What should I prepare?">
Prepare the text and an image with alternative text.
</AccordionItem>

<AccordionItem value="review" title="Who reviews the page?">
Ask another member of the editorial team.
</AccordionItem>
</Accordion>
```

| Property                 | Values, default, and effect                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `accordion.type`         | `single` (default) opens one item; `multiple` allows several.                                                 |
| `accordion.collapsible`  | Boolean. Default: `true`. In single mode, allows closing the open item.                                       |
| `accordion.defaultValue` | Initially open item value; none by default. Use a string for `single`, a JSON list of strings for `multiple`. |
| `accordion.appearance`   | `quiet` or `tint`. Uses the site setting when omitted.                                                        |
| `accordion-item.value`   | Unique text identifier. Generated when omitted. Set it when using `defaultValue`.                             |
| `accordion-item.title`   | Question or heading text. No title by default.                                                                |
| `accordion-item.content` | Plain body text. No text by default; the default Markdown slot is rendered after it.                          |

Put only `accordion-item` children in `accordion`. Each item accepts default Markdown, a `<template #title>` slot instead of the title property, and a `<template #content>` slot instead of the content property.

| `card.title`        | Heading text. No title by default.                                                           |
| `card.description`  | Short text below the title. No description by default.                                       |
| `card.footer`       | Text in the footer. No footer by default.                                                    |
| `card.to`           | Page reference, site path, or external URL. No link by default.                              |
| `card.target`       | Link target, such as `_blank` for a new tab. Default: current tab.                           |
| `card.icon`         | Icon name. No icon by default.                                                               |

| `card.appearance`   | `quiet` or `tint`. Uses the site setting when omitted.                                       |

| `path`       | Endpoint path, such as `/api/articles`. No path by default.                                                                               |
| `groups`     | **Required for rendering.** Non-empty JSON list of groups, each with a unique non-empty `label` and non-empty `entries` list. No default. |
| `appearance` | `quiet` or `tint`. Uses the site setting when omitted.                                                                                    |

Content belongs in `groups`. The default slot is accepted by the Markdown policy but is not displayed. Use `title` for a general header, or `method` with `path` for an endpoint header.

Each object in `entries` accepts these fields:

| Field         | Values, default, and effect                                                                                                |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `name`        | **Required.** Non-empty text, unique within the group.                                                                     |
| `annotation`  | Type text, such as `string`. Omitted by default.                                                                           |
| `required`    | Boolean. Default: `false`. Adds a required badge.                                                                          |
| `optional`    | Boolean. Default: `false`. Adds `?` to the name. Do not combine with `required: true`.                                     |
| `deprecated`  | Boolean. Default: `false`. Marks an obsolete field.                                                                        |
| `since`       | Version text. Omitted by default.                                                                                          |
| `default`     | Text describing the field's default value. Quote numbers and booleans, for example `default: "false"`. Omitted by default. |
| `description` | Text below the signature. Backticks format inline code. Omitted by default.                                                |

Optional text fields must be non-empty when supplied. Invalid groups or entries stop rendering with a diagnostic; they are not silently removed. Generated entry IDs must be unique. Across multiple panels, use distinct group/name combinations to avoid duplicate anchors. The [API panel guide]($docs/components/api-reference) explains header variants and direct links to entries.

## img — ordinary Markdown images

Use Markdown image syntax for an image without a visible caption. The `img` tag is the built-in renderer for this syntax.

![A city skyline at sunset](/images/content-demo-workspace.jpg "City skyline")

**Copy into your Markdown file:**

```mdc [content/docs/component-example.md]
![A city skyline at sunset](/images/content-demo-workspace.jpg "City skyline")
```

| Property | Values, default, and effect                                                                                                                    |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `src`    | Image path or URL; supplied inside parentheses. Needed to display an image.                                                                    |
| `alt`    | Alternative text; supplied inside square brackets. Describe meaningful images; use empty text only for decorative images. Default: empty text. |
| `title`  | Optional quoted title after the path. No title by default; not a visible caption.                                                              |
| `width`  | Optional numeric image width. No explicit width by default.                                                                                    |
| `height` | Optional numeric image height. No explicit height by default.                                                                                  |

No slots. Normal images follow the site-wide image zoom setting. Use `figure` below for explicit dimensions, a visible caption, or per-image zoom control.

## figure

Show an image with a caption. Select the image to try zoom; Escape closes it.

<Figure src="/images/content-demo-workspace.jpg" alt="High-rise buildings beneath a sunset sky" caption="The city at the end of the day." aspect="video" fit="cover" zoom />

**Copy into your Markdown file:**

```mdc [content/docs/component-example.md]
<Figure src="/images/content-demo-workspace.jpg" alt="High-rise buildings beneath a sunset sky" caption="The city at the end of the day." aspect="video" fit="cover" zoom />
```

| Property     | Values, default, and effect                                                                                                                          |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src`        | **Required.** Image path or URL.                                                                                                                     |
| `alt`        | **Required.** Alternative text describing the image.                                                                                                 |
| `caption`    | Text below the image. Defaults to `alt` when omitted.                                                                                                |
| `width`      | Number or numeric string. Explicit image width; unset by default.                                                                                    |
| `height`     | Number or numeric string. Explicit image height; unset by default.                                                                                   |
| `bleed`      | `outside` extends the figure beyond the text column. Omit for normal width.                                                                          |
| `aspect`     | `auto` (fallback), `video` (16:9), `wide` (21:9), `square` (1:1), or `portrait` (4:5).                                                               |
| `placement`  | `inline` (default), `start`, `end`. A direct figure inside `flow` wraps text from 40 rem of flow width. Below that width it stays in document order. |
| `frame`      | `default` (default), `none`. `none` removes the surface and puts the caption below the image.                                                        |
| `focus`      | `center` (default), `top`, `bottom`, `left`, `right`. Keeps this part of a cropped image visible.                                                    |
| `fit`        | `cover` (fallback) fills and can crop; `contain` keeps the whole image inside the chosen aspect.                                                     |
| `zoom`       | Boolean, or `auto` (default). `true` enables zoom; `false` disables it; `auto` follows the site setting. Use `:zoom="true"` or `:zoom="false"`.                       |
| `appearance` | `quiet` or `tint`. Uses the site setting when omitted.                                                                                               |

The default Markdown slot adds content between the image and its caption. `caption` is plain text; when omitted, the visible caption uses `alt`. The Markdown policy accepts `bleed` as text: `"true"` also expands the figure; other text values keep normal width. Prefer `outside`.

| Property                    | Values, default, and effect                                                                                 |
| --------------------------- | ----------------------------------------------------------------------------------------------------------- |

| `quiz-question.options`     | **Required.** JSON list of at least two choices, each with unique non-empty `text` and a boolean `correct`. |

Put at least two `quiz-question` children in `quiz` to show navigation, results, and retry controls. Use `quiz-question` on its own for a single question with a retry button. For `single`, exactly one choice must have `correct: true`. For `multiple`, at least one must be correct; the reader must select all correct choices and no incorrect choices. ## toc

Insert a collapsible table of contents for this page. Open it to jump to a component.

<Toc title="Find a component" :depth="2" :open="false" />

**Copy into your Markdown file:**

```mdc [content/docs/component-example.md]
<Toc title="Find a component" :depth="2" :open="false" />
```

| Property | Values, default, and effect                                                                                            |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `title`  | Text. Default: the site’s translated table-of-contents label.                                                          |
| `depth`  | Number. Keeps headings up to this level; `2` means level-two headings. Default: all headings supplied by the page TOC. |

## Ordinary Markdown and custom components

Paragraphs, headings, **bold text**, *emphasis*, lists, links, tables, blockquotes, horizontal rules, and code fences do not need an MDC tag. Ginko Docs styles them automatically. For example:

```md [content/docs/article.md]
## Before you publish

Check **names** and *dates*.

- Read the text.
- Open each link.

> Keep the reader's next action clear.

| Task | Owner |
| --- | --- |
| Review | Editorial team |

> [!NOTE]
> Save your draft before closing the editor.
```

GitHub-style alerts support `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, and `CAUTION`. Use a named notice component above when you need its title, icon, or appearance properties.

This page lists the built-in authoring contract. Site-specific tags need their own registration; they are not available on every Ginko Docs site. For example, `release-status` belongs to this documentation app's [custom component example]($docs/customization/custom-components). Ask the site developer to register a new component before using a custom tag.
