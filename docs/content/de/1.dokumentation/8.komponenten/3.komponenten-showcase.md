Dieses Labor deckt jeden öffentlichen Autoren-Tag ab. Oberflächen erscheinen in beiden Stilen; strukturelle Helfer einmal.

Live-Beispiele, kopierbares Markdown und alle Eigenschaften findest du in der [vollständigen MDC-Referenz]($docs/components/mdc-components).

## Hinweise und Prosa

> [!NOTE]
> GFM-Hinweise bleiben außerhalb von Ginko Docs lesbar.

> [!WARNING]
> Strukturierte Werte und boolesche Optionen stehen als statisches JSON im Attribut, etwa `:zoom="false"`.

<Accordion appearance="quiet" defaultValue="rich-content">
<AccordionItem value="rich-content" title="Kann ein Akkordeon vollständiges Markdown enthalten?">
Akkordeon-Inhalte unterstützen gewöhnliches Markdown und verschachtelte Ginko-Komponenten.

- Listen behalten ihre Struktur.
- Interaktive Kindelemente behalten ihren Zustand, wenn das Akkordeon geschlossen wird.

</Steps>
