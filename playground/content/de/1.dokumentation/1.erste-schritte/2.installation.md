Installiere die Abhängigkeiten und starte danach die Nuxt-App.

## Paketänderungen

Der Starter nutzt das öffentliche Ginko-Content-Paket:

```json
{
  "dependencies": {
    "@lupinum/ginko-content": "^0.3.0"
  }
}
```

## Nuxt-Modul

Registriere das Ginko-Content-Modul in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: ["@lupinum/ginko-content"],
});
```

## Verifikation

Führe die Installation und die normalen Projektprüfungen aus:

```bash
vp install
vp check
vp test
```

::alert{title="Eine Quelle der Wahrheit" type="warning"}
Content lebt in `content/`, und der Collection-Vertrag lebt in `content.config.ts`. Füge diesem Filesystem-Starter keinen CMS-Sync-Schritt und keine generierten CMS-Typen hinzu.
::
