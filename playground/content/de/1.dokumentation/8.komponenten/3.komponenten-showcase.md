## Hinweise und Prosa

> [!NOTE]
> GFM-Hinweise bleiben außerhalb von Ginko Docs lesbar.

> [!WARNING]
> Strukturierte Werte und boolesche Optionen gehören in Komponenten-YAML.

**Quiet**

::note{title="Ein Inhaltsmodell" appearance="quiet"}
Navigation, Suche und Agenten-Markdown entstehen aus demselben Dokument.
::

**Tint**

::note{title="Ein Inhaltsmodell" appearance="tint"}
Navigation, Suche und Agenten-Markdown entstehen aus demselben Dokument.
::

::success{title="Validierung bestanden"}
Inhalt und übersetzte Identitäten stimmen überein.
::

::warning{title="Übersetzungen prüfen"}
Halte entsprechende Sprachbäume strukturell gleich.
::

::error{title="Route nicht verfügbar"}
Die Collection enthält kein passendes Dokument.
::

::idea{title="Redaktionelle Idee"}
Beginne mit einem funktionierenden Beispiel.
::

**Quiet**

::aside{label="Kontext" appearance="quiet"}
Ergänzender Kontext bleibt lesbar, ohne das Dokument zu unterbrechen.
::

**Tint**

::aside{label="Kontext" appearance="tint"}
Ergänzender Kontext bleibt lesbar, ohne das Dokument zu unterbrechen.
::

::

## Akkordeons

**Quiet**

::accordion{appearance="quiet"}
:::accordion-item{value="content" title="Wer besitzt den Inhalt?"}
Ginko Content besitzt Identität, Routen, Sprachen, Suche und Agentenausgabe.
:::
:::accordion-item{value="presentation" title="Wer besitzt die Darstellung?"}
Ginko Docs besitzt Shell und Komponentensystem.
:::
::

**Tint**

::accordion{appearance="tint"}

:::
:::accordion-item{value="presentation" title="Wer besitzt die Darstellung?"}

:::
::

**Vollständiges Markdown**

::accordion{appearance="quiet" defaultValue="rich-content"}
:::accordion-item{value="rich-content" title="Kann ein Akkordeon vollständiges Markdown enthalten?"}
Akkordeon-Inhalte unterstützen gewöhnliches Markdown und verschachtelte Ginko-Komponenten.

- Listen behalten ihre Struktur.
- Interaktive Kindelemente behalten ihren Zustand, wenn das Akkordeon geschlossen wird.

::::steps{mode="numbered" appearance="quiet"}
### Inhalt hinzufügen

Schreibe Prosa und verschachtelte Komponenten in den Inhalt des Elements.

### Ergebnis prüfen

Schließe und öffne das Akkordeon erneut, ohne den Inhalt zu verlieren.
::::
