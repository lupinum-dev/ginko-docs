Dieses Labor deckt jeden öffentlichen Autoren-Tag ab. Oberflächen erscheinen in beiden Stilen; strukturelle Helfer einmal.

## Hinweise und Prosa

> [!NOTE]
> GFM-Hinweise bleiben außerhalb von Ginko Docs lesbar.

> [!WARNING]
> Strukturierte Werte und boolesche Optionen gehören in Komponenten-YAML.

::note{title="Quiet-Notiz" appearance="quiet"}
Numerische Präfixe steuern die Reihenfolge, ohne Teil der Route zu werden.
::

::info{title="Tint-Information" appearance="tint"}
Navigation, Suche und Agenten-Markdown entstehen aus demselben Dokument.
::

::success{title="Validierung bestanden"}
Inhalt und übersetzte Identitäten stimmen überein.
::

::warning{title="Übersetzungen prüfen"}
Halte entsprechende Sprachbäume strukturell gleich.
::

::error{title="Route nicht verfügbar"}
Die Collection enthält kein passendes Dokument.
::

::idea{title="Redaktionelle Idee"}
Beginne mit einem funktionierenden Beispiel.
::

::aside{label="Quiet-Aside" appearance="quiet"}
Ergänzender Kontext kann visuell zurückhaltend bleiben.
::

::aside{label="Tint-Aside" appearance="tint"}
Tint erzeugt eine stärkere Pause im Lesefluss.
::

::excerpt{label="Auszug" source="Ginko-Inhaltsmodell" appearance="quiet"}
Ein kanonisches Dokument liefert jede Leser- und Agentenausgabe.
::

::excerpt{label="Auszug" source="Ginko-Inhaltsmodell" appearance="tint"}
Das Erscheinungsbild ändert sich, die Bedeutung nicht.
::

::dropcap{lines="3"}
Ginko Docs verwandelt strukturiertes Markdown in eine Dokumentations-Site für Leser und Software-Agenten. Die Initiale gibt längerer Prosa einen deutlichen Einstieg, ohne ihre Quellstruktur zu verändern.
::

Drücke :kbd[⌘] + :kbd[K], um die Suche zu öffnen.
