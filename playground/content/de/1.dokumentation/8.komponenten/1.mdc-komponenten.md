Ginko Docs ordnet 46 verfasste Tags seinen Prose- und MDC-Komponenten zu. Map und portable Komponenten-Policy werden aus `@lupinum/ginko-docs/components` exportiert. Die folgenden Tabellen bilden den vollständigen Autorenvertrag aus `layer/tags.ts` ab.

Verwende statische Werte in Markdown. Die Content-Policy weist dynamische Vue-Bindings zurück.

```mdc [content/docs/example.md]
::callout{title="Route prüfen" type="warning" icon="lucide:triangle-alert"}
Verwende die öffentliche Route und nicht den Quelldateinamen.
::
```

## Tabellen lesen

- Eine als **Pflicht** markierte Prop muss vorhanden sein.
- `asset` ist eine Medienreferenz aus dem Portabilitätsvertrag.
- `default` bezeichnet Inhalt zwischen öffnendem und schließendem Tag.
- Ein Strich bedeutet, dass die portable Autoren-Policy keine Prop oder keinen Slot freigibt.

Interne Vue-Props wie `class`, `inStack` oder Quiz-Zustand sind absichtlich ausgeschlossen. Sie gehören nicht zum Vertrag für verfasstes Markdown.

```mdc [content/docs/project-structure.md]
:::folder{name="app"}
::::file{name="app.config.ts" annotation="Website-Identität"}
::::
:::
::
```

## Tag-Map erweitern

Führe die öffentliche Map zusammen, statt die 46 eingebauten Einträge zu kopieren:

```ts [nuxt.config.ts]
import { ginkoDocsComponentTags } from "@lupinum/ginko-docs/components";

export default defineNuxtConfig({
  content: {
    componentPolicy: {
      components: {
        "api-playground": {
          kind: "block",
          props: {
            method: { type: "string", required: true },
            path: { type: "string", required: true },
          },
          slots: ["default"],
          media: null,
        },
      },
    },
    markdown: {
      tags: {
        ...ginkoDocsComponentTags,
        "api-playground": "MdcApiPlayground",
      },
    },
  },
});
```

Registriere eine eigene MDC-Komponente global, weil der Markdown-Renderer Tag-Ziele dynamisch auflöst. Registriere einen Ginko-Content-Agent-Serializer, wenn kopiertes oder rohes Markdown eine andere Darstellung als die standardmäßige XML-Komponentenausgabe benötigt.
