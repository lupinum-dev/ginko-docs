Dokumentation soll für Menschen, Crawler und Coding-Agents nutzbar sein. Das Theme leitet alle drei Oberflächen aus derselben validierten Collection ab.

## Verfügbare Oberflächen

| Schnittstelle   | Zweck                                           | Ausprobieren                                                                                                     |
| --------------- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Raw Markdown    | Eine Seite ohne Darstellungs-Chrome             | [Diese Seite als Markdown öffnen](/raw/de/dokumentation/grundlagen/plattform-funktionen/agent-schnittstellen.md) |
| `llms.txt`      | Kompakter Seitenkatalog                         | [llms.txt öffnen](/de/llms.txt)                                                                                  |
| `llms-full.txt` | Vollständiger crawlbarer Docs-Korpus            | [llms-full.txt öffnen](/de/llms-full.txt)                                                                        |
| MCP             | Strukturierte Tools `list-pages` und `get-page` | MCP-Client mit `/mcp` verbinden                                                                                  |

Der englische Katalog liegt unter [`/llms.txt`](/llms.txt) und [`/llms-full.txt`](/llms-full.txt).

::alert{title="Produktionsdetail" type="warning"}
Statisch prerenderte HTML-Dateien führen keine HTTP-Content-Negotiation aus. Nutze bei direkt ausgelieferten generierten Dateien die explizite Raw-Route.
::

## MCP-Vertrag

`list-pages` findet kanonische Dokumente und `get-page` liefert ein ausgewähltes Dokument. Beide arbeiten auf Collection-Daten; dadurch kann keine visuelle Docs-Seite unbemerkt im Agent-Katalog fehlen.
