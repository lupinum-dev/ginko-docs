Markdown soll die übliche Schreibfläche abdecken, ohne eigene Komponenten zu erzwingen.

## Absätze und Hervorhebung

Nutze Absätze für Dokumentationstext. Nutze **fetten Text**, wenn Leser eine Einschränkung beachten müssen, und nutze `Inline-Code` für Befehle, Pfade, Funktionsnamen und Konfigurationsschlüssel.

Nutze `const locale = "de"`{lang="ts"}, wenn ein Inline-Snippet Syntax-Highlighting braucht.

## Listen

Nutze nummerierte Schritte für Abläufe:

1. Collection definieren.
2. Collection abfragen.
3. Dokument rendern.
4. Generierte Ausgabe prüfen.

Nutze ungeordnete Listen für zusammengehörige Fakten:

- Routen stammen aus Collection-Pfaden.
- Inhaltsverzeichnis-Links stammen aus Überschriften.
- Suche stammt aus geparstem Content.

## Fußnoten

Fußnoten verlinken Hinweise im Text mit einer Definition am Dokumentende.[^markdown-footnotes]

[^markdown-footnotes]: Die Fußnotenliste wird automatisch aus den verwendeten Definitionen erzeugt.

## Code

Ein normaler Codeblock rendert mit Syntax-Highlighting:

```ts
import { docs } from "~/content.config";

const { page } = await useContentPage(docs);
```

Setze Zeilennummern hinter die Sprache, um einzelne Zeilen hervorzuheben:

```ts [content.config.ts]
import { defineContentConfig } from "@lupinum/ginko-content/config";

export const docs = defineContentConfig({
  root: "content/de",
});
```

Nutze die Shiki-Notation, wenn eine Zeile unabhängig von der Metadatenzeile hervorgehoben werden soll:

```ts [content.config.ts]
const source = "content/de";
const collection = "docs"; // [!code highlight]
const locale = "de";
```

Nutze die Shiki-Diff-Notation, wenn hinzugefügte und entfernte Zeilen sichtbar sein sollen:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@nuxt/content"], // [!code --]
  modules: ["@lupinum/ginko-content"], // [!code ++]
});
```

## Tabellen

| Quelle                       | Owner         | Zweck                  |
| ---------------------------- | ------------- | ---------------------- |
| `content.config.ts`          | Ginko Content | Collection-Schemas     |
| `content/de/1.dokumentation` | Docs-Autoren  | Deutsche Seitenquelle  |
| `content/en/1.docs`          | Docs-Autoren  | Englische Seitenquelle |
| `app/pages/docs`             | Nuxt-App      | Docs-Route-Rendering   |
