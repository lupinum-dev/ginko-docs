Prose-Komponenten gestalten normale Markdown-Tags. Ginko Docs liefert sie direkt mit, damit Content ohne eigene Komponenten auf jeder Seite lesbar bleibt.

## Überschriften

Überschriften erzeugen IDs und Einträge im Inhaltsverzeichnis. Die rechte Leiste soll beim Scrollen die aktive Überschrift hervorheben.

### Zwischenüberschrift

Die Hierarchie aus `h2`, `h3` und `h4` soll ruhig wirken: genug Abstand fuer Orientierung, aber keine riesigen Spruenge im Lesefluss.

#### Detailueberschrift

Detailueberschriften markieren kurze Unterabschnitte, ohne den Absatz danach optisch zu zerlegen.

## Text, Links und Listen

Absatztext bleibt schmal genug zum Lesen, nutzt eine klare Zeilenhoehe und darf **wichtige Begriffe** hervorheben. Betonungen wie _redaktionelle Hinweise_ und Inline-Code wie `siteConfig.site.name` muessen im Satz sauber sitzen.

Interne Links wie [Markdown-Syntax]($docs/essentials/markdown-syntax) und externe Links wie [Nuxt](https://nuxt.com) verwenden dieselbe Prose-Link-Komponente.

- Ungeordnete Listen haben kompakte, aber nicht gequetschte Zeilen.
- Verschachtelte Listen bleiben lesbar:
  - zweite Ebene mit eigener Markierung
  - genug Abstand zum naechsten Punkt
- Langer Listentext darf umbrechen, ohne dass Marker und Text unruhig wirken.

1. Geordnete Listen zeigen klare Schritte.
2. Die Nummerierung soll mit mehrzeiligem Text stabil bleiben.
3. Verschachtelte Eintraege funktionieren ebenfalls:
   1. erster Unterpunkt
   2. zweiter Unterpunkt

> Ein Zitat oder redaktioneller Hinweis soll wie Teil des Leseflusses wirken: sichtbar abgesetzt, aber nicht wie eine schwere Karte.

## Code

Inline-Code wird im Satz gerendert, Codebloecke sollen die wiederverwendbaren Komponenten `ProsePre` und `ProseCode` verwenden.

```ts
export default defineAppConfig({
  content: {
    bleed: true,
  },
});
```

## Tabellen

Tabellen sollen kompakte Abstände und Rahmen behalten:

| Element | Komponente   | Zweck                     |
| ------- | ------------ | ------------------------- |
| `p`     | `ProseP`     | lesbare Absatzbreite      |
| `h2`    | `ProseH2`    | Abschnittsstruktur        |
| `pre`   | `ProsePre`   | Codeblock mit Kopierknopf |
| `table` | `ProseTable` | kompakte Vergleichsdaten  |
