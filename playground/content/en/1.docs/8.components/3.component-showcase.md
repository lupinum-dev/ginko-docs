This page is the visual fixture for the complete component set. It renders every public authored tag with realistic content so maintainers can compare spacing, typography, interaction, responsive behavior, and theme treatment in one place.

## Notices and supporting prose

Semantic notices communicate different levels of context without changing the surrounding reading flow.

::note{title="Background"}
Numeric prefixes control order but never appear in public routes.
::

::info{title="Generated behavior"}
Navigation, search, and agent-readable output derive from the same content documents.
::

::warning{title="Check translated identities"}
Keep the same numeric identity for equivalent English and German pages.
::

::success{title="Ready to publish"}
The content, navigation, and public references passed validation.
::

::error{title="Configuration failed"}
The configured collection does not contain a matching route.
::

::idea{title="Editorial idea"}
Use a focused example before adding an exhaustive reference table.
::

::alert{title="Compatibility alert" type="danger"}
Update the layer and its peer dependency as one supported set.
::

::callout{title="Custom callout" type="note" icon="lucide:book-open"}
The generic callout accepts an explicit semantic type and icon.
::

::danger{title="Danger alias"}
This tag renders the same error treatment as `error`.
::

::warn{title="Warning alias"}
This tag renders the same warning treatment as `warning`.
::

::aside{label="Editorial note"}
An aside adds supporting context that is useful but not required for the main task.
::

::passage{label="Excerpt"}
One content model supplies the rendered page, search record, raw Markdown, and agent catalog.
::

::dropcap{lines="3"}
Ginko Docs turns structured Markdown into a documentation site for readers and software agents. The drop cap gives long-form editorial passages a distinct opening without changing their source structure.
::
