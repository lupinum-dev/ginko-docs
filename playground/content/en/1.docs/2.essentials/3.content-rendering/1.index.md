title: Content Rendering
description: Render Ginko Content documents with the starter prose and component tags.
---

Ginko Content parses Markdown into an AST and `<ContentRenderer>` turns that AST into Vue output.

## Renderer contract

The renderer receives a full document:

```vue
<ContentRenderer :value="page" />
```

That contract keeps page metadata, body, table of contents, and component context together.

## Component catalog

Generic prose and MDC components come from `@lupinum/content-components`. The starter keeps only business-specific tags such as contact, imprint, consent, privacy services, and gallery behavior. Ginko Content maps Comark component tags through `content.markdown.tags` in `nuxt.config.ts`.

## What to verify

Generated docs pages should render headings, paragraphs, code, tables, cards, callouts, and nested components without hydration errors.
