Ginko Content exposes focused query helpers instead of requiring pages to understand storage. This site uses those helpers for the route, sidebar, page navigation, locale switcher, and command palette.

## Query surface

```ts
const page = await useContentPage("docs");
const tree = await useContentTree("docs");
const results = await useContentSearch("docs", query);
const variants = await useContentVariants("docs", page.value);
```

Lower-level collection queries also support `one`, `many`, `paginate`, `resolveOne`, `tree`, and `neighbors`. Backlinks and variants connect documents without duplicating relationships in UI state.

## See it working

1. Open search with <kbd>⌘</kbd> <kbd>K</kbd> or the header control.
2. Search for “localization” or “agent interfaces”.
3. Open a result and confirm the sidebar, breadcrumbs, table of contents, and previous/next links agree on the route.

::callout{title="Provider choice" icon="lucide:database-zap"}
The default local index is lightweight. Larger sites can use Pagefind or a provider-owned search implementation without changing authored content.
::
