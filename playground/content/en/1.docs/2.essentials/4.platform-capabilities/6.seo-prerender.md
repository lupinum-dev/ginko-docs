Production output is part of the content contract. A successful local render is not enough: every collection route must prerender cleanly and appear in discovery output.

## Generated for each document

- page title and description,
- canonical URL and language alternatives,
- `TechArticle` and breadcrumb JSON-LD,
- sitemap entries,
- previous/next relationships,
- Open Graph metadata and image endpoint.

## Release checks

```bash
vp check
vp test
vp run build
```

The build uses strict prerendering, so broken internal routes and rendering failures stop the release instead of shipping partial documentation.

::callout{title="Inspect the output" icon="lucide:scan-search"}
View the page source for canonical, `hreflang`, Open Graph, and JSON-LD output, then compare the route against `/sitemap.xml`.
::
