This group turns the playground into an acceptance test you can browse. Its pages share one collection, one navigation tree, and one canonical document identity across locales.

## From files to interfaces

```text
content files → validated collection → pages and tree
              → search and sitemap → raw, LLM, and MCP output
```

The route page uses `useContentPage`, the sidebar uses `useContentTree`, and related navigation comes from collection neighbors. Search, prerendering, and agent routes consume the same canonical collection data.

::callout{title="One source of truth" icon="lucide:git-merge"}
Navigation, localized routes, search results, the sitemap, and agent output are derived from the content collection—not copied into parallel configuration.
::
