Ginko Content pairs locale variants by their canonical content position. English and German can use natural folder and file names while the locale switcher still lands on the matching page.

## Translated path example

| Locale  | Public route                                                      |
| ------- | ----------------------------------------------------------------- |
| English | `/docs/essentials/platform-capabilities/localization`             |
| Deutsch | `/de/dokumentation/grundlagen/plattform-funktionen/lokalisierung` |

Both routes represent this document. The page also emits canonical and `hreflang` metadata for crawlers.

::callout{title="Try it" icon="lucide:mouse-pointer-click"}
Use the locale switcher in the header. You should stay on Localization while every translated path segment changes.
::

## Configuration contract

The consumer declares locales once. `defineGinkoDocsConfig` builds locale-aware collections and the layer uses the same route map for i18n, links, and prerendering.
