Documentation should be usable by people, crawlers, and coding agents. The theme derives all three surfaces from the same validated collection.

## Available surfaces

| Interface       | Purpose                                      | Try it                                                                                       |
| --------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Raw Markdown    | One page without presentation chrome         | [Open this page as Markdown](/raw/docs/essentials/platform-capabilities/agent-interfaces.md) |
| `llms.txt`      | Compact page catalog                         | [Open llms.txt](/llms.txt)                                                                   |
| `llms-full.txt` | Full crawlable documentation corpus          | [Open llms-full.txt](/llms-full.txt)                                                         |
| MCP             | Structured `list-pages` and `get-page` tools | Connect an MCP client to `/mcp`                                                              |

Localized catalogs are available at [`/de/llms.txt`](/de/llms.txt) and [`/de/llms-full.txt`](/de/llms-full.txt).

::alert{title="Production detail" type="warning"}
Static prerendered HTML does not perform HTTP content negotiation. Use the explicit raw route when a deployment serves generated files directly.
::

## MCP contract

`list-pages` discovers canonical documents and `get-page` returns a selected document. Both operate on collection data, so a page cannot exist in the visual docs while silently disappearing from the agent catalog.
