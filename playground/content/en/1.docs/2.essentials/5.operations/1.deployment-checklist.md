Use this checklist after the content and application builds pass. It catches failures that only appear at the package or deployment boundary.

## Before deployment

- Install the packages from the exact release artifacts.
- Build the production application with strict prerendering enabled.
- Confirm every expected documentation and blog route was generated.
- Inspect the sitemap, search index, raw Markdown, and LLM catalogs.

## Runtime smoke test

Open representative nested pages, use the navigation tree, run a search, and check the browser console. Test every configured locale when the site is multilingual.
