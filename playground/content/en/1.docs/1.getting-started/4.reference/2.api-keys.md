API key pages are a good test for nested reference navigation because they usually sit below a broader reference folder.

## Create a key

Create keys in the product dashboard and store them in server-only environment variables.

## Rotate a key

Rotation should be documented as a short operational path:

1. Create a replacement key.
2. Deploy the replacement environment variable.
3. Revoke the old key after verification.

## Avoid frontend exposure

Never expose private API keys in client payloads, public runtime config, or static generated HTML.
