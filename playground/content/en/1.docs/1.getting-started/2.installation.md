Install dependencies, then run the Nuxt app.

## Package changes

The starter uses the public Ginko Content package:

```json
{
  "dependencies": {
    "@lupinum/ginko-content": "^0.3.0"
  }
}
```

## Nuxt module

Register the Ginko Content module in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: ["@lupinum/ginko-content"],
});
```

## Verification

Run dependency installation and the normal project checks:

```bash
vp install
vp check
vp test
```

::alert{title="Single source of truth" type="warning"}
Content lives in `content/` and the collection contract lives in `content.config.ts`. Do not add a CMS sync step or generated CMS types to this filesystem starter.
::
