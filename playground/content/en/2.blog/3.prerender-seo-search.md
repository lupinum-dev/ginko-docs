Static content migrations fail most often in the quiet parts of the site: metadata, sitemap output, client search, and stale route data.

## Static output

Generated output must include the route HTML, payload data, robots file, and sitemap files. The docs and blog pages should be present without depending on a long-running server.

## SEO checks

Each content page should have a unique title, description, canonical URL, Open Graph title, and Open Graph description. Blog details should also render the author name resolved from the author collection.

## Search checks

Search must index docs and blog pages from the Ginko Content source. The command center should return content results for terms such as `reference`, `author`, and `prerender`.

## Browser checks

The in-app browser verification should open generated or dev-served routes, inspect DOM metadata, test navigation links, and capture screenshots for both desktop and mobile widths.
