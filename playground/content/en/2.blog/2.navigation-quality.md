Good documentation navigation is boring in the best way. It should make the current location obvious, expose sibling pages, and avoid decorative structure that slows scanning.

## Sidebar groups

The docs sidebar uses sections for the broad doc areas and groups for local clusters. A group heading should be text, not a second route source, unless the folder also has an index page that users can read.

## Mobile behavior

Mobile docs need two controls: one for the docs sidebar and one for the current page table of contents. Combining them saves space at the cost of discoverability, so this template keeps them separate.

## Acceptance criteria

The migration is not done until both desktop and mobile layouts show:

- the active docs section,
- the active page,
- nested reference children,
- badges where content asks for them,
- a usable "On this page" drawer.
