    Three rules for every component

    1. Text blocks use a rounded line. Callouts, asides, excerpts, and blockquotes share it. Callouts use variant A: the tone lives in the line and the title, the text stays neutral. Framed adds a light tint behind the callout; quiet is the line alone, like GitHub alerts.
    2. Objects use a frame with a panel. Code, tables, cards, API panels, files, figures, and quizzes: titles and tabs in the head, content in the panel, captions and actions in the foot. Radii are concentric: 14, 10, 8.
    3. Layout has no chrome. Layout, column, flow, and center add no border, background, or padding. The only option is surface="muted" or "tint", which uses the same tokens as frames.
    4. From PR #70: align, gap, stack, surface, column sizes xs to xl, media="cover", Flow, figure placement, bleed, and frame="none". See Layouts and flow.
    5. Removed: the in-text table of contents component and the five layout border types.
    6. API panel: the name comes first, the type is muted, "Required" is a neutral mark, and the default and version share one quiet line.
    7. One selected state everywhere: the current page, active tab, section switcher, and code tree file use the same chip.
    8. Quiet is a token set, and the shell works standalone, inset, or inside a website.

    Prototype: Gallery and Layouts and flow show every component. Quickstart, Code blocks, and Tokens have real guide content.
